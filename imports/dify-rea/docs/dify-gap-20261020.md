## 1. Bản đồ chức năng Dify (route `web/app`)

| Nhóm | Route / thành phần | Ghi chú |
|---|---|---|
| Ứng dụng | `apps`, `app/[appId]/{overview, configuration, workflow, logs, annotations, deploy, access-point, access-config}` | Chế độ: chat, chatflow, workflow, agent, text-generate; xuất/nhập DSL; nhân bản; mẫu (`templates`) |
| Agent (mới) | `agents/[agentId]/{configure, access, logs, monitoring}` | "agent_v2", gói agent có `soul` (env, secret_refs, tools) |
| Workflow | `components/workflow`: canvas, `block-selector`, `node-actions-menu`, `header` (checklist, **lịch sử phiên bản**, chạy thử), `comment`, `collaboration` (CRDT, con trỏ nhiều người, WebSocket) | Cộng tác thời gian thực + bình luận trên canvas |
| Node (26 loại) | start, end, answer, llm, agent, agent-v2, knowledge-retrieval, knowledge-base, question-classifier, parameter-extractor, if-else, code, template-transform, http, tool, iteration, loop, list-operator, variable-assigner, assigner, document-extractor, data-source, **human-input**, **trigger-schedule**, **trigger-webhook**, trigger-plugin | Có retry, xử lý lỗi theo node (`DEFAULT_RETRY_*`) |
| Tri thức | `datasets/{create, connect, create-from-pipeline}`, `[datasetId]/{documents, hitTesting, pipeline, settings, api, access-config}` | **Thử truy xuất (hit testing)**, pipeline RAG, kho ngoài (external KB), metadata |
| Công cụ / plugin | `tools` (builtin, api, **mcp**, workflow-as-tool), `plugins`, `marketplace`, `integrations` | Workflow xuất bản thành tool; MCP client |
| Khác | `snippets` (khối dùng lại), `skills`, `explore/installed` (app cho người dùng cuối), `form/[token]` (form human-input công khai), tag, API key, billing, education | |

## 2. xT Studio đang có (`src/contracts.ts`)

- `AppKind`: chat, workflow, agent.
- `NodeKind` (13): start, llm, retrieval, condition (true/false hoặc nhiều nhánh if/else), template, aggregate, http, output, xt_tool, question_classifier, parameter_extractor, list_operator, human_approval.
- Biến: `{{node_id}}` và `{{node_id.truong}}` (đọc trường của kết quả JSON object).
- Tool agent (2): `knowledge_search`, `calculator`.
- Có: tài liệu/tri thức (PDF, DOCX, TXT/MD/CSV), mô hình, MCP routes, app công khai, luồng stream.

## 3. Khoảng trống — xếp theo giá trị cho xT

| Ưu tiên | Chức năng Dify | Vì sao quan trọng với xT | Gợi ý trong xT |
|---|---|---|---|
| 1 | **Node gọi công cụ xT (tool/MCP)** | Workflow AI làm việc thật trên dữ liệu doanh nghiệp | **Đã làm (20/10):** node `xt_tool` "Công cụ xT" chỉ gọi tool trong `xtToolNames`, tham số là mẫu JSON `{{biến}}` (escape chuỗi JSON), chạy bằng capability của phiên xT; chế độ độc lập báo lỗi 400. Còn lại: gắn JD agent (AgentHR) |
| 1 | **Node người duyệt (human-input)** | Đúng triết lý xT: AI soạn, người quyết | **Đã làm (23/10):** node `human_approval` "Người duyệt" tạo yêu cầu xT thật (`describe_model` kiểm `primitive=request` → `create_record` trên mô hình yêu cầu do node chọn, mặc định `advance_request`, trường lấy từ mẫu JSON `{{biến}}` → `submit_request`, tiêu đề/nội dung/gợi ý người duyệt vào `note`). Lượt chạy chuyển `waiting`, ảnh chụp tiếp tục lưu ở bảng `run_waits`. Người chạy bấm "Kiểm tra và chạy tiếp" (`POST /api/runs/:id/resume`, cần phiên xT): Studio đọc `get_record` → nhánh `approved`/`rejected`; chưa duyệt → 409; quá `timeout_hours` → 410 "Đã quá hạn duyệt.". Quyết định chỉ đi qua `decide_request` của xT trên Desk (mật khẩu + TOTP, SoD, audit); `decide_request` không nằm trong `xtToolNames`. **Còn lại:** chạy tiếp nền khi yêu cầu được duyệt (cần capability xT cho trigger/worker), kích hoạt theo lịch chưa tạo được yêu cầu; mô hình yêu cầu chung (tiêu đề + nội dung) trong xT thay cho việc mượn `advance_request` |
| 1 | **Nhật ký chạy + theo dõi** (logs, monitoring) | Truy vết từng lượt chạy | Gắn audit xT: mỗi lượt có trace, ai chạy, node nào bị chặn |
| 2 | Kích hoạt theo lịch / webhook | Báo cáo sáng, đồng bộ định kỳ | trigger-schedule chạy qua worker xT (hàng đợi sẵn có) |
| 2 | **Thử truy xuất tri thức** (hit testing) | Kiểm tra câu trả lời có nguồn | Màn "Thử truy xuất" trong Tri thức |
| 2 | Lịch sử phiên bản + xuất bản | Đổi workflow có kiểm soát | Xuất bản = request xT cần duyệt (giống gói cấu hình) |
| 2 | question-classifier, parameter-extractor, if-else đa nhánh, list-operator, code, iteration/loop | Đủ khối để dựng nghiệp vụ | **Đã làm (20/10):** if-else nhiều nhánh (`cases` + `else`, 14 phép so sánh, and/or; dạng true/false cũ giữ nguyên), `question_classifier` (nhánh theo ID nhóm), `parameter_extractor` (JSON mode, kiểm kiểu/bắt buộc/lựa chọn, đọc bằng `{{node.truong}}`), `list_operator` (lọc, sắp xếp, giới hạn, lấy phần tử). variable-assigner (variable aggregator) đã có tương đương là node `aggregate`, không thêm. **Chưa làm:** code, iteration/loop |
| 3 | Chú thích câu trả lời (annotations) | Sửa câu trả lời mẫu | |
| 3 | Snippets, mẫu app, xuất/nhập DSL | Dùng lại | |
| 3 | Cộng tác thời gian thực, bình luận trên canvas | Hay nhưng tốn công | Để sau |
| — | Marketplace plugin, billing, education | Không phù hợp phạm vi | Bỏ |
